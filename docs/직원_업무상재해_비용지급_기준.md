# 직원 업무상 재해(워크샵·행사 중 사고) 비용 지급 기준

- 적용 대상: 우리 병원 전 직원(상시근로자 20명, 산재보험 당연가입 사업장)
- 담당: 원무과장(접수·서류·신고), 원장(경로 결정·지급 승인)
- 기준 확인일: 2026-09-08 (법령 개정 시 갱신)
- 성격: 원내 운영 기준. 개별 사안이 애매하면 노무사 또는 근로복지공단(1588-0075)에 확인한다.

---

## 0. 한 장 요약

| 순서 | 판단 | 기준 | 결과 |
|---|---|---|---|
| 1단계 | 업무상 재해인가 | 병원이 주관·지시·비용 부담한 행사의 공식 일정 중 사고인가 | 예 → 2단계 / 아니오 → 개인 치료(병원 임의 지원 가능) |
| 2단계 | 얼마나 다쳤나 | 진단서의 요양기간(3일 이내 vs 4일 이상), 휴업 일수(3일 이상 여부) | 아래 3단계 표로 |
| 3단계 | 누가 얼마를 내나 | 요양 4일 이상 → 산재보험 처리가 기본. 요양 3일 이내 → 병원이 근로기준법 재해보상 | 지급표(4장) 적용 |

기본 원칙 세 가지

1. 업무상 재해에 해당하고 요양이 4일 이상이면 산재보험 신청을 기본으로 한다. 우리 병원은 30인 미만이라 산재를 처리해도 보험료가 오르지 않는다.
2. 산재보험이 안 주는 부분(요양 3일 이내 치료비, 휴업 시 임금의 나머지 30%, 비급여)은 병원이 정해진 기준대로 보전한다.
3. 휴업이 3일 이상 필요하면 사고일로부터 1개월 안에 산업재해조사표를 고용노동부에 제출한다. 산재 신청 여부와 무관한 별도 의무다.

## 1. 1단계 — 업무상 재해 판단

### 법령 기준
산업재해보상보험법 시행령 제30조(행사 중의 사고): 운동경기·야유회·등산대회 등 각종 행사 참가가 사회통념상 노무관리 또는 사업운영상 필요하다고 인정되고, 다음 중 하나에 해당하면 그 행사(참가를 위한 준비·연습 포함) 중 사고는 업무상 사고로 본다.

1. 사업주가 행사 참가 시간을 근무시간으로 인정한 경우
2. 사업주가 참가를 지시한 경우
3. 사전에 사업주의 승인을 받아 참가한 경우
4. 그 밖에 사업주가 참가를 통상적·관례적으로 인정한 경우

대법원 판례의 일관된 기준: 행사·모임의 주최자, 목적, 내용, 참가 인원과 강제성, 운영 방법, 비용 부담 등을 종합해 "행사의 전반적인 과정이 사용자의 지배·관리를 받는 상태"였는지로 판단한다. 근무시간 종료 후 노조가 개최한 체육대회 중 부상은 사업주 지배·관리 밖이라고 본 사례가 있다(대법원 2005두11418).

### 우리 병원 워크샵 상황별 구분

| 사고 상황 | 판단 | 처리 |
|---|---|---|
| 공식 프로그램 중(교육, 레크리에이션, 체육활동, 단체 이동, 단체 식사) | 업무상 재해 | 2단계로 |
| 병원이 주관·비용 부담한 저녁 회식(1차) 중 | 업무상 재해로 보는 것이 원칙 | 2단계로 |
| 숙소 등에서의 자유시간, 개인 외출, 자율 참가 2차 자리 | 원칙적으로 업무상 재해 아님 | 개인 치료(건강보험). 병원 임의 지원은 원장 결정, 과세 대상 |
| 음주 후 개인적 일탈, 사적 다툼 | 업무상 재해 아님 | 위와 같음 |
| 애매한 경우 | 판단을 근로복지공단에 맡긴다 | 산재 신청 → 불승인 시 개인 치료로 전환 |

판단 포인트: 우리 병원 워크샵은 원장이 일정을 정하고 전 직원 참석을 요청하며 비용을 병원이 부담한다. 따라서 공식 일정 중 사고는 위 요건 2·3·4에 해당한다.

## 2. 2단계 — 요양기간과 휴업 판단

진단서 또는 초진소견서로 판단한다. 두 숫자가 처리 경로를 갈라놓는다.

### 요양기간 (치료가 필요한 기간)
- 3일 이내: 산재보험 요양급여·휴업급여가 지급되지 않는다(산재보험법 제40조 제3항, 제52조 단서). 병원이 근로기준법 제78조·제79조에 따라 직접 보상한다.
- 4일 이상: 산재보험 요양급여 대상. 신청 기본.

### 휴업 일수 (실제로 출근하지 못하는 날)
- 산재 휴업급여: 취업하지 못한 기간이 4일 이상이면 첫날부터 전 기간 평균임금의 70% 지급(3일 이내면 미지급).
- 산업재해조사표 제출 의무: "3일 이상의 휴업이 필요한 부상". 고용노동부 해석은 재해 발생일을 제외하고 다음 날부터 연속 3일 이상, 휴일·공휴일 포함, 실제 출근 여부보다 의사 소견을 기준으로 본다.
- 따라서 초진소견서의 "취업치료 가능 여부" 항목이 중요하다. 실제로 근무가 가능한 상태면 그대로 기재되도록 의사에게 사실대로 상황을 설명한다(조작이 아니라 실제 상태를 반영시키는 것).

### 직무별 근무 가능성 (손·손가락 부상 기준)

| 직무 | 부목·캐스트 상태에서 근무 | 조치 |
|---|---|---|
| 행정실, 원무, 외래 접수 | 대체로 가능 | 통원 시간만 유급 처리 |
| 방사선사, 병리사 | 검사 종류에 따라 제한 | 가능한 업무로 조정 |
| 병동, 내시경실 | 환자 직접 처치·손위생·세척 곤란(감염관리) | 경증 업무로 전환. 전환 불가 시 휴업 → 3일 이상이면 산업재해조사표 |

## 3. 3단계 — 처리 경로

### 경로 A. 산재보험 처리 (요양 4일 이상의 기본 경로)
- 신청 주체: 근로자 본인. 치료받는 병원 원무과가 대행할 수 있다(근로자 동의). 2018-01-01부터 사업주 확인 절차가 폐지되어 병원 동의는 필요 없고, 근로복지공단이 사업주 의견을 직접 조회한다.
- 서류: 요양급여신청서, 초진소견서(의료기관 발급), 재해 경위서. 온라인은 근로복지공단 토탈서비스.
- 공단 결정: 신청일로부터 7일 이내 원칙(조사 필요 시 지연).
- 승인 전 낸 본인부담금: 승인 후 요양비 청구로 환급(급여 항목만). 비급여는 환급되지 않는다.
- 병원(사업주) 할 일: 공단의 사업주 의견 조회에 사실대로 회신. 휴업 3일 이상이면 산업재해조사표 제출.
- 우리 병원의 불이익: 없음. 상시근로자 30명 이상 사업장에만 개별실적요율(보험료 할증·할인)이 적용된다.

### 경로 B. 병원 직접 보상 (요양 3일 이내, 또는 근로자가 산재 신청을 원치 않는 소액 건)
- 근거: 근로기준법 제78조(요양보상, 치료비 전액), 제79조(휴업보상, 평균임금 60%). 산재보험이 지급하지 않는 부분은 사업주 책임이다.
- 조건
  1. 근로자에게 산재 신청 권리가 유지됨을 안내하고 확인서를 받는다(권리 포기 요구 금지).
  2. 치료비는 본인부담금과 비급여 전액을 영수증 기준 실비로 지급한다.
  3. 휴업 3일 이상이 필요한 부상이면 경로 B라도 산업재해조사표는 제출한다.
  4. 건강보험 적용 진료였다면 환수 위험을 인지한다(아래 5장). 환수가 오면 병원이 부담한다.
- 근로자가 나중에(3년 이내) 산재를 신청하면 병원이 이미 지급한 금액은 산재급여에서 공제된다(산재보험법 제80조, 근로기준법 제87조).

### 경로 C. 개인 치료 (업무상 재해 아님)
- 건강보험으로 본인 치료. 병원의 지원은 의무가 아니며, 지원 시 복리후생 성격의 과세 근로소득이다.

## 4. 비용 항목별 지급표

법정 = 법으로 정해진 것. 병원기준 = 우리 병원이 정한 추가 보전(원장이 바꿀 수 있음).

| 항목 | 경로 A (산재) | 경로 B (병원 직접) | 구분 |
|---|---|---|---|
| 진료비 본인부담금(급여) | 공단 부담. 승인 전 결제분은 요양비 청구로 환급 | 병원 실비 지급 | 법정 |
| 비급여(재료대, 선택 치료 등) | 공단 미지급 → 병원 부담. 사전 협의 없는 고가 선택 치료는 원장 승인 후 | 병원 실비 지급 | 병원기준 |
| 약제비(급여) | 공단 | 병원 | 법정 |
| 산재 신청용 초진소견서 | 공단이 의료기관에 지급(근로자 부담 없음) | 해당 없음 | 법정 |
| 회사 제출용 진단서 발급비 | 병원 | 병원 | 병원기준 |
| 통원 교통비 | 공단 미지급(응급 이송비만 별도) → 병원 실비(영수증) | 병원 실비 | 병원기준 |
| 통원에 쓴 근무시간 | 유급 처리 | 유급 처리 | 병원기준 |
| 휴업 1~3일 | 산재 휴업급여 없음 → 병원이 임금 100% 지급(법정 최소 60%) | 같음 | 60%는 법정, 100%는 병원기준 |
| 휴업 4일 이상 | 공단 휴업급여 70%(첫날부터) + 병원 30% 보전 | 해당 시 산재로 전환 | 70%는 법정, 30%는 병원기준 |
| 위로금 | 원장 재량 | 원장 재량 | 병원기준(과세) |

세무 처리
- 근로기준법에 따른 요양보상금·휴업보상금과 산재보험급여는 비과세 근로소득(소득세법 제12조 제3호). 급여대장에 "재해보상금(비과세)"으로 구분 기재한다.
- 법정 범위를 넘는 임의 지원(임금 30% 보전, 위로금, 업무상 재해가 아닌 건의 지원)은 원칙적으로 과세 근로소득이다. 세무사에게 항목별 처리를 확인한다.
- 병원 측 비용은 재해보상비 또는 복리후생비로 필요경비 처리.

## 5. 반드시 지켜야 할 의무

### 산업재해조사표 (산업안전보건법 제57조 제3항, 시행규칙 제73조)
- 대상: 사망 또는 3일 이상 휴업이 필요한 부상·질병.
- 기한·제출처: 재해 발생일부터 1개월 이내, 관할 지방고용노동관서(고용노동부 울산지청). 근로자대표 확인란 필요.
- 산재 요양급여신청서를 공단에 냈더라도 조사표는 따로 내야 한다.
- 과태료: 미제출 1차 700만원, 2차 1,000만원, 3차 1,500만원. 거짓 제출 1,500만원.

### 산재 은폐 금지 (산업안전보건법 제57조 제1항, 제170조)
- 은폐 또는 은폐 교사·공모: 1년 이하 징역 또는 1천만원 이하 벌금.
- 병원 직접 보상 자체가 은폐는 아니다. 그러나 조사표 대상인데 내지 않거나, 산재 신청을 막거나 불이익을 주면 은폐로 판단될 수 있다. 산재 신청은 근로자 고유 권리다.

### 건강보험 급여 제한 (국민건강보험법 제53조 제1항 제4호)
- 업무상 재해로 다른 법령(산재보험, 근로기준법)의 보상을 받게 되는 경우 건강보험 급여는 제한된다.
- 업무상 재해를 건강보험으로 치료하고 병원이 본인부담금만 내주는 방식은 건강보험공단 부당이득 환수 대상이 될 수 있다. 소액 건에서 흔히 쓰이지만 정식 경로는 아니다. 이 위험이 경로 A를 기본으로 두는 이유다.

### 소멸시효 (산재보험법 제112조)
- 요양급여·휴업급여 3년, 장해급여 5년. 병원 직접 보상 후에도 근로자는 이 기간 안에 산재를 신청할 수 있다.

### 취업규칙
- 10인 이상 사업장은 취업규칙이 필수다. 재해보상 조항이 없으면 다음 취지로 추가한다: "업무상 재해는 산업재해보상보험법에 따라 처리하고, 같은 법이 보상하지 않는 부분은 근로기준법과 이 기준에 따라 병원이 보상한다."

## 6. 절차 체크리스트 (담당: 원무과장)

사고 당일
- [ ] 응급처치 후 진료. 진료 시 "직장 행사 중 부상"임을 사실대로 말하게 한다.
- [ ] 사고 경위서: 일시, 장소, 진행 중이던 프로그램, 구체적 동작, 목격자, 사진. 원장 확인 서명.
- [ ] 진단서 또는 초진소견서 확보: 진단명, 요양기간, 취업치료 가능 여부.

1~3일 이내
- [ ] 1단계·2단계 판단 → 경로 결정. 결정 기록지(7장) 작성, 원장 승인.
- [ ] 근로자 면담: 경로 설명, 산재 신청 권리 안내, 지급 기준 안내. 경로 B면 확인서 서명.
- [ ] 경로 A: 근로자가 산재 신청(치료 병원 대행 가능). 공단 사업주 의견 조회 오면 사실대로 회신.
- [ ] 업무 조정: 병동·내시경실은 환자 직접 처치 배제.

1개월 이내
- [ ] 휴업 3일 이상 → 산업재해조사표 제출(고용노동부 울산지청), 근로자대표 확인.
- [ ] 비용 지급: 영수증·진료비 세부내역서 수령 → 지급표대로 지급 → 급여대장 비과세 항목 구분.

종결
- [ ] 치료 종결 확인, 지급 총액 정리, 서류 일체 보관(최소 3년, 소멸시효 고려).
- [ ] 다음 워크샵 기획 시 이번 사고 원인을 프로그램 점검 항목에 반영.

## 7. 결정 기록지 (양식)

```
사고 일시 / 장소:
직원명 / 직무:
사고 당시 일정(공식 프로그램 / 회식 / 자유시간):
진단명:                       요양기간:        일
취업치료 가능 여부:            예상 휴업:       일
1단계 판단: 업무상 재해 ( 예 / 아니오 / 공단 판단에 위임 )
2단계 판단: 요양 ( 3일 이내 / 4일 이상 )   휴업 ( 0 / 1~2 / 3 / 4일 이상 )
처리 경로: ( A 산재 / B 병원 직접 / C 개인 )
산업재해조사표: ( 대상 아님 / 제출 예정 ___월 ___일 )
지급 항목·금액:
근로자 안내·확인서: ( 완료 ___월 ___일 )
결정자: 원장 ______   기록: 원무과장 ______
```

근로자 확인서 문구(경로 B): "본인은 이번 부상에 대해 산업재해보상보험 신청 권리가 유지됨을 안내받았으며, 병원이 지급한 금액은 향후 산재보험급여와 중복될 경우 정산될 수 있음을 확인합니다."

## 8. 이번 건(손가락 염좌, 부목·캐스트) 적용

1. 요양기간: 손가락 염좌에 부목·캐스트를 했다면 통상 2~4주 요양이다. 4일 이상이므로 산재 요양급여 대상이다.
2. 업무상 재해 여부: 사고가 워크샵 공식 일정 중이었는지 확인한다. 공식 일정이면 경로 A(산재)가 기본이다. 자유시간 개인 활동이었으면 경로 C에 병원 임의 지원 여부만 결정한다.
3. 휴업 여부: 직무를 본다. 행정·외래·원무는 근무 가능이 보통이므로 휴업 0일, 산업재해조사표 대상이 아니다. 병동·내시경실이면 업무 전환을 먼저 하고, 전환이 안 돼 3일 이상 쉬면 조사표를 낸다. 4일 이상 쉬면 휴업급여 70%에 병원이 30%를 보전한다.
4. 지급: 4장 지급표대로. 산재 승인 전 낸 본인부담금은 근로자가 요양비 청구로 환급받고, 비급여·교통비·진단서비는 병원이 실비 지급한다.
5. 근로자가 "소액이니 산재 안 하겠다"고 하면 경로 B로 처리할 수 있다. 확인서를 받고, 건강보험 환수 위험은 병원이 안는다는 점을 원장이 인지한 뒤 결정한다.
